# 硬件连接（ESP32-S3 + INMP441）

本文是设备的接线、供电与自检说明。固件侧的引脚默认值在
`firmware/sdkconfig.defaults`，可在 `menuconfig → 诊录助手-采音配置` 修改。

## 1. 物料

| 部件 | 型号 | 说明 |
| --- | --- | --- |
| 主控板 | ESP32-S3-WROOM-1-N16R8 | 16 MB Flash + 8 MB OPI PSRAM，板载 CH343 USB 转串口 |
| 麦克风 | INMP441 | I2S 数字 MEMS，24 bit，3.3 V 供电 |
| 连接线 | 杜邦线 6 根 | 尽量短（≤ 15 cm），SCK/SD 不要与电源线并排长距离走 |

## 2. 接线

| INMP441 | 接到 ESP32-S3 | 说明 |
| --- | --- | --- |
| `VDD` | `3V3` | **只能 3.3 V**，接 5 V 会损坏 |
| `GND` | `GND` | 必须与主控共地 |
| `L/R` | `GND` | 接地 = 数据放在左声道；接 3V3 则放右声道（固件会自动选有声的那路，但建议固定 GND） |
| `SCK`（BCLK） | `IO5` | I2S 位时钟，ESP32 主模式输出 |
| `WS`（LRCLK） | `IO4` | 声道选择时钟，ESP32 主模式输出 |
| `SD`（DIN） | `IO6` | 音频数据，麦克风 → ESP32 |

```
        ┌───────────────┐
 3V3 ───┤ VDD       SCK ├──── IO5  (BCLK)
 GND ───┤ GND        WS ├──── IO4  (WS)
 GND ───┤ L/R        SD ├──── IO6  (DIN)
        └───────────────┘
```

### 为什么是 IO4 / IO5 / IO6

| 引脚 | 被谁占用 | 结论 |
| --- | --- | --- |
| IO33–IO37 | OPI PSRAM | 不能用 |
| IO26–IO32 | Flash | 不能用 |
| IO41 / IO42 | 板载 OLED（若焊接） | 避开 |
| IO43 / IO44 | UART0（CH343 串口，日志与音频流） | 不能用 |
| IO19 / IO20 | 原生 USB-Serial-JTAG | 避开（身份验签固件走这里） |
| IO0 | BOOT 按键 | 避开 |
| **IO4 / IO5 / IO6** | 空闲 | **用这三个** |

> 如果换板子或换引脚，改 `menuconfig` 里的三个 GPIO 即可，不用改代码。

## 3. 供电与接地

- INMP441 电流很小（< 1 mA），直接取板载 3V3 即可；
- **共地是第一位**：麦克风 GND 必须回到主控 GND，否则噪声底会异常高或全是 0；
- 长线或电机环境：SCK/SD 串 33 Ω 电阻、就近加 0.1 µF 去耦，可明显降低爆音（端侧 5 帧中值滤波能挡一部分，但源头处理更好）。

## 4. 上电自检

烧录后串口（COM5，921600）应看到：

```
I (866) audio_in: init ok: 16000 Hz, bclk=5 ws=4 din=6, gain=0 dB, hp=80 Hz
I (873) vad: init: enter=9.0 exit=6.0 dB, hang=14帧, pre=15帧, min=10帧, max=1500帧, peak=500/400
I (882) segmap: init: 16000 Hz, 最多 512 段/会话
I (888) app: 开始采音，20 ms/帧
I (10913) app: 统计: 帧 502 | 语音占比 0.0% | 噪声底 -75.0 dB | 段表 0 条
```

安静房间的噪声底应在 **-80 ~ -65 dB**；说话时语音占比 20%~60%。

## 5. 故障对照

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 噪声底 `-100.0 dB`、语音占比 0% | 没供电 / 没共地 / SD 没接 | 查 VDD、GND、SD |
| 有数据但一直是 `peak=32767` | 增益过大或贴太近 | `menuconfig` 把 `GAIN_DB` 降到 0 或负值 |
| 日志 `10 秒内没读到样本` | I2S 没时钟：SCK/WS 没接 | 查 SCK(IO5)、WS(IO4) |
| 噪声底正常但段切得很碎 | 环境噪或门限偏严 | 调 `VAD_EXIT_DB` / `VAD_HANG_MS` |
| 串口乱码 | 波特率不对 | 固件与控制台都应为 921600（自定义 UART） |

## 6. 两个 USB 口别搞混

| 接口 | 芯片 | 用途 |
| --- | --- | --- |
| 板载 CH343（`COM5`） | USB 转 UART，接 UART0 | **烧录、日志、音频流**（本固件用这个） |
| 原生 USB-Serial-JTAG | ESP32-S3 内置 | `firmware/device-key` 的身份验签协议走这里 |

两块固件目前是分开的：采音固件在 CH343 口，身份固件在原生 USB 口。
合并成一份固件时，需要先决定身份协议走哪个口（见 `docs/device-audio.md` 已知限制 2）。

## 7. 封装与演示注意

- 麦克风开孔不要被外壳挡住，孔后留 2~3 mm 空腔；
- 演示时麦与医生距离 0.5~1 m，说话正常音量即可（噪声底 -75 dB 时，正常说话约 -30 dB）；
- 板子放在显示器旁时，注意 Wi-Fi 天线方向，避免 USB 线缠绕在电源适配器上引入嗡声。
